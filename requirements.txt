# === Mock 后端（testcases/mes/ 的业务全链路用例需要，见 mock_server/） ===

# 报 ImportError: No module named 'fastapi'——分成两个文件省下的那点安装时间，
# 远抵不过"新同事照 README 做完却跑不起来"的代价。

# === 契约驱动测试（testcases/contract/，见 docs/wave1-contract-handoff.md） ===
# schemathesis 从 docs/openapi.json 生成请求做属性测试，所以它和 pytest / jsonschema
# 必须装在同一个环境里——只装 pytest 的人跑 pytest -m contract 会 ImportError，
# 和上面 Mock 后端段是同一个理由。
# 只 pin 直接依赖 schemathesis：它自己声明的依赖（hypothesis、httpx、werkzeug、
# yarl、click 等）交给 pip 解析。这里不照抄一份传递依赖清单，是因为
# 传递依赖一旦由本文件接管，就会和 schemathesis 自身的版本约束打架，
# 而 requirements.lock（pip-compile 产物）本来就会把解析结果全量钉死。
# 实测（python 3.12.10）解析结果：hypothesis==6.169.1、hypothesis-jsonschema==0.23.1、
# hypothesis-graphql==0.13.2、httpx==0.28.1、werkzeug==3.1.9、yarl==1.25.1、
# starlette-testclient==0.4.1、pytest-subtests==0.14.2、harfile==0.5.0、
# backoff==2.2.1、pyrate-limiter==3.9.0、junit-xml==1.9、tomli==2.5.0、tomli-w==1.2.0。
# 注意 schemathesis 3.39 对 OpenAPI 3.1 仍是实验特性（FastAPI 0.115 默认导出 3.1.0），
# 代码里显式调用了 schemathesis.experimental.OPEN_API_3_1.enable()，
# 升级 schemathesis 前必须先确认这个开关还在。
schemathesis==3.39.16
